# 첫 프로젝트 푸시 검토 — 2026-10-07

판정: **현재의 인증 선행 기반을 첫 개발 커밋으로 공유할 준비가 되었다.** 가입·로그인·JWT·업무 API의 구현 완료나 운영 배포 준비 완료를 의미하지 않는다.

## 확인 결과

- 최종 로컬 `mvnw -B -Pmysql-it verify` 성공: 기본/단위 10개 + MySQL·Redis 통합 12개, 총 22개. 실패·오류·건너뜀 0.
- 두 마이그레이션의 실제 MySQL 적용/재실행, UNIQUE/FK/CHECK/중복 등록 경쟁, 서명 커서 및 공개 API 계약을 확인했다.
- 개발 DB의 실제 기동 검증 및 컬럼 대조 기록도 함께 포함했다.
- 데이터베이스 계정은 loopback 전용 개발/테스트 기본값이다. GitHub 토큰, 운영 비밀번호, 개인키가 새 커밋 대상에 없는지 패턴 검사를 수행했다. 완전한 비밀 탐지를 보장하는 검사는 아니다.
- `.idea`, `target`, 로그, `.env`, 키 파일, 개인용 `LOCAL_SETUP.md`는 제외한다.
- Linux용 `mvnw`는 LF 및 실행 권한을 지정한다. Maven Wrapper를 포함해 별도 Maven 설치 없이 빌드한다.
- 원본 설계 6개 파일의 SHA-256 일치를 확인하고, 문서 원본은 Git 줄바꿈 변환에서 제외한다. 개발용 절대 경로는 원문 보존 자료에만 남아 있고 일반 실행 안내는 프로젝트 상대 경로를 사용한다.
- README/개발 순서/마이그레이션 안내의 과거 ‘테이블 없음’ 내용을 현재 범위로 정정했다. 공개 API는 A01/A02뿐이다.
- GitHub Actions에 Java 21 + 별도 MySQL/Redis 통합 검증을 추가했다. 사용 Action은 공식 v4 참조의 커밋 SHA로 고정했다.

## Git 반영 방식

기존 원격 main의 `Initial commit`을 부모로 사용한다. 기존 README의 저장소 소개를 보존하고 실행/테스트/구현 범위를 확장했다. 새 커밋 메시지는 사용자 요청대로 `.`이다. 강제 푸시를 사용하지 않는다.

원격 CI는 푸시 후 Actions에서 확인해야 한다. 이 보고서에 기록된 22개 통과는 로컬 최종 검증 결과다.
